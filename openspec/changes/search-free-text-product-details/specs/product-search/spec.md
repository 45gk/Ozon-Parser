# Spec Delta

## Purpose

Позволяет запускать поиск товаров Ozon по ссылке на выдачу или по свободному
названию и сохранять вместе с позициями выдачи подробные данные их карточек.

## ADDED Requirements

### Requirement: Поиск принимает ссылку или свободный текст

Система SHALL принимать в качестве цели поиска либо ссылку Ozon на
`/category/...` или `/search/...`, либо непустую текстовую фразу и
преобразовывать фразу в поисковый URL Ozon.

#### Scenario: Ссылка на выдачу

- **WHEN** пользователь отправляет ссылку `https://www.ozon.ru/category/...?text=macbook`
- **THEN** создаётся поиск с этой ссылкой без изменения её параметров

#### Scenario: Название товара

- **WHEN** пользователь отправляет текст `macbook air m5`
- **THEN** создаётся поиск по адресу `https://www.ozon.ru/search/?text=macbook+air+m5`
- **AND** в истории запрос отображается как `macbook air m5`

#### Scenario: Ссылка на карточку вместо выдачи

- **WHEN** пользователь отправляет ссылку `/product/...`
- **THEN** запрос отклоняется с сообщением, что нужна ссылка на категорию или поиск

#### Scenario: Слишком короткий текст

- **WHEN** пользователь отправляет текст короче двух символов
- **THEN** запрос отклоняется с ошибкой валидации

### Requirement: Выдача сохраняет подробности карточек

Система SHALL при включённом разборе карточек запрашивать данные каждой
позиции выдачи и сохранять их вместе с позицией: продавца, бренд, наличие,
описание, цену с картой и характеристики.

#### Scenario: Успешный разбор позиции

- **WHEN** поиск завершился и для позиции получена карточка
- **THEN** позиция хранит подробные поля карточки и полный разобранный JSON
- **AND** страница поиска показывает, что карточка разобрана

#### Scenario: Разбор отключён

- **WHEN** пользователь запускает поиск с выключенным разбором карточек
- **THEN** сохраняются только поля плитки выдачи
- **AND** поиск не выполняет запросы карточек

#### Scenario: Ошибка отдельной карточки

- **WHEN** одна из карточек не загрузилась или не разобралась
- **THEN** поиск остаётся успешным
- **AND** ошибка сохраняется у этой позиции
- **AND** остальные позиции продолжают разбираться

#### Scenario: Повторный поиск

- **WHEN** пользователь повторяет поиск из детальной страницы
- **THEN** новый запуск использует тот же режим разбора карточек
